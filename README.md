# Melvin Langat — Portfolio

A single-page personal portfolio site for Melvin Langat, a front-end & back-end developer based in Kenya. Built with plain HTML, CSS, and JavaScript — dark, techy theme with glassmorphism cards and scroll-reveal animations.

## Tech Stack

- HTML5
- CSS3 (custom styles, no framework)
- Vanilla JavaScript

## Features

- Responsive single-page layout with a sticky, auto-hiding nav bar
- Circular profile photo in the nav and hero section
- Hero section with a photo, floating profile card, and call-to-action buttons
- **About** section with a skills breakdown (Front-End, Back-End, Tools & Others)
- **Projects** section showcasing:
  - [DriveSphere](https://github.com/melvinlagz/Drivesphere) — PHP/MySQL car marketplace
  - Rental Management System — React/Tailwind PWA
  - [Kamara Sacco](https://github.com/melvinlagz/Kamara-Sacco) — SACCO concept site
  - [The Green Fork](https://github.com/melvinlagz/The-Green-Fork-Hotel) — cafe landing page
  - [Nexora](https://github.com/melvinlagz/Nexora) — digital studio landing page
  - Matatu Booking System — PHP/MySQL booking platform
- **Contact** section with email, phone, LinkedIn, and GitHub links, plus a contact form that opens a pre-filled email
- Scroll-reveal animations via IntersectionObserver

## Getting Started

This is a static site with no build step required.

1. Clone the repo:
   ```bash
   git clone https://github.com/melvinlagz/Portfolio.git
   ```
2. Open `index.html` in your browser, or serve the folder with any static server, e.g.:
   ```bash
   npx serve .
   ```
